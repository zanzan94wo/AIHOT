# 站点

这个站自己的东西：名字、文案、品牌、页面，以及启用哪些模块。步骤见 [把它改成你的行业](../docs/customize.md)。

| 文件 | 内容 |
|---|---|
| `site.ts` | 站名、行业词、出刊时间、首页和关于页文案、分享图文字、条目与日报周报月报上的说法、公开接口的分类、备案号 |
| `models.ts` | 具名的模型和每一步默认用哪个（没写的步骤用 `.env` 里配的那一个） |
| `brand/` | 图标、Logo（`Logo.tsx`）、分享图和海报上的字标（`wordmark.svg`、`wordmark-dark.svg`，可选）、日报周报月报的报头字（`nameplates/`）、关于页的二维码（`contact/`，可选） |
| `pages/` | 使用规则、隐私说明（模板，上线前按实际情况改写） |
| `public/` | 发布在网站根目录的固定文件（站名、地址等占位符替换后发布）：`robots.txt`、`manifest.webmanifest`、`openapi-v1.json`，以及可选的 `.well-known/security.txt` |
| `changelog.json` | 更新日志 |
| `modules/` | 启用哪些模块：`index.ts`、`server.ts`、`web.ts` 三份清单，列出仓库根目录 `modules/<名字>/` 里要用的模块，默认都为空，见 [架构](../docs/architecture.md#模块) 的“模块” |

## 生图提示词热榜

本站按新站定制。内容类别继续区分提示词实战、模型更新、创作工具、生图研究、评测解析与规则动态，保持日报的发布与评论编排语义；主题页独立提供模型、创作用途与方法入口。模型主题按标签匹配，因此没有厂商作为报道主体的个人实践、同时比较多个模型的文章也能被找到。

首批公开信源为 Midjourney Updates、Google Gemini Blog、Black Forest Labs、Hugging Face Blog、fal Blog 和 Simon Willison。Hugging Face 订阅混合了不同作者与机构的文章，按 T2 社区来源处理，不把转载平台视为每篇文章的一手发布方。综合来源仍需经过生图相关性预筛；仅被收录不代表成为精选。来源地址于 2026-11-02 核验，网站调整后应在后台重新预览。默认只展示摘要与原文链接，不直接复制整套提示词或原文图片集。

上线前需要运营者决定：

- `SITE_URL`、部署地区、运营主体、联系方式，以及适用的备案信息。
- 确认 `site/pages/terms.md` 和 `privacy.md`，补齐版本、生效日期、日志保留期与实际使用的第三方服务；当前仍是模板。
- 为编辑步骤选择文本或视觉模型并配置后端密钥、预算。这里的编辑模型和网站收录的生图模型是两件事；本站不替读者调用生图服务。是否使用视觉输入按实际模型能力设置，不默认宣称已核验图片效果。
- 用自己标注的 100–200 条生图素材校准评分。`industry/selection.ts` 暂保留原数值，`gold.example.jsonl` 只是虚构的格式示例，不是已完成的行业评测。
- 补充常看的中文创作者和模型专属信源；X、公众号等付费渠道、全文展示与转载均需另行决定并核实授权。
- 当前默认关闭自动采集、模型调用、飞书与 IndexNow。准备就绪后再分别启用需要的开关。日报仍按北京时间 08:00、周报周一 10:00、月报每月 1 日 10:30 出刊。

`site/changelog.json` 的日期是定制记录，不代表已经部署上线。此次不迁移旧站数据，也不重算历史文章。

本机验证环境使用了将公网域名解析为 `198.18.0.0/15` 的 Fake-IP DNS，正式采集预览会被后端的 SSRF 防护拒绝。已下载 6 个公开来源的真实样本，并通过本地预览回放验证标题、网址与日期解析；部署时需使用正常公网 DNS，或配置已支持的 `EGRESS_PROXY_URL` 后再次预览。不要为此关闭地址或证书校验。
